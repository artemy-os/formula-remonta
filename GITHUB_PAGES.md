# GitHub Pages

Проект настроен для статической публикации на GitHub Pages.

## Проверка сборки

```bash
npm ci
npm run build:pages
```

Готовый сайт появится в папке `out/`.

## Публикация

1. Создайте пустой репозиторий GitHub.
2. Загрузите в него содержимое этой папки в ветку `main`.
3. В настройках репозитория откройте **Settings → Pages**.
4. В поле **Source** выберите **GitHub Actions**.
5. После публикации настройте DNS домена `formularem.ru` по инструкции GitHub Pages.

Файл `public/CNAME` подключает собственный домен. Если сайт будет работать
только по адресу вида `username.github.io/repository`, удалите `public/CNAME` и
передайте имя репозитория при сборке через переменную `PAGES_BASE_PATH`.
